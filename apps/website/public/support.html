Before contacting support

Share evidence, not secrets.

Useful reports are specific enough to reproduce while keeping credentials and personal information out of the message.

Safe to includeApp version, operating system version, approximate time, test or sandbox environment, screen name, redacted request ID, expected behavior, and observed behavior.
Do not includeSeed phrase, private key, authentication token, API key, complete wallet backup, production customer record, unredacted personal data, or signing material.
Payment concernStop before signing if the amount, asset, network, recipient, fee, or context is unexpected. Do not rely on a support message to override transaction facts.
Security concernUse the security channel and begin with a minimal impact description. Wait for a coordinated method before sending sensitive proof.

Frequently asked

Preview support basics.

Can support recover my seed phrase or private key?

No. VelarumPay support should never ask for a recovery phrase or private key, and the server does not hold user signing material.

Where can I download the app?

The Android Preview APK is available from the Personal page. The same official download link is kept when the published build changes.

Can a merchant or agent approve a request for me?

No. The current product boundary requires user review and local signing for real payments by default.

Does a pilot request create a production account?

No. It begins an evaluation conversation. Production access remains subject to product, legal, security, operational, and release decisions.
