Built for human confirmation

A wallet that stays between your AI agent and your assets.

VelarumPay receives structured payment requests from trusted agent workflows, shows the merchant, recipient, amount, chain, asset, order details, and risk warnings, then waits for explicit user approval before signing.

01

Payment request inbox

AI-created intents arrive as reviewable requests with order context, chain data, and status history.

02

Local wallet signing

Private keys stay on the phone. Signing happens only after the user confirms and authenticates.

03

XLM and USDC demos

Current demo flows support Stellar XLM and Base USDC payment request handling.

04

Relay connection

A lightweight relay connects desktop agents, Telegram demos, and the mobile wallet without exposing keys.

Security boundary

The agent proposes. The wallet decides.

No cloud private keys

OpenClaw, Telegram integrations, and relay services never receive seed phrases or signing material.

Human-in-the-loop approval

Every payment request is shown before signing, including recipient, asset, amount, and irreversible-payment warnings.

Payment proof trail

Requests, status updates, and transaction hashes are tracked so demos can be inspected end to end.
