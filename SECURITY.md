## Report a Vulnerability

Use [GitHub private vulnerability reporting](https://github.com/Paytobe/Paytobe/security/advisories/new). Do not open a public issue for an unpatched vulnerability.

Include the affected component and version, impact, reproduction steps, and a minimal proof of concept. Do not include production credentials, seed phrases, private keys, personal data, or funds belonging to another person.

## Supported Versions

Security fixes target the latest release and the current `main` branch. Older development snapshots may not receive separate fixes.

## Scope and Testing

The wallet core, Android and iOS clients, Platform API, protocol packages, SDKs, connectors, websites, and runnable examples are in scope. Private infrastructure and user accounts are not authorization to test production systems.

Use local or explicitly authorized test environments. Do not disrupt services, perform social engineering, access another user's data, or submit real mainnet transactions as part of a report.

## Disclosure

The maintainers will triage reports privately, coordinate a fix and release when appropriate, and publish an advisory after affected users have a reasonable opportunity to update.
